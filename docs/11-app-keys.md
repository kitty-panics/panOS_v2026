# 应用内快捷键

除系统级快捷键外，panOS 预配置的 Ranger、Neovim、Zsh 与 Xfce Terminal 还有各自的键位方案。

## Ranger (终端文件管理器)

启动: `Ctrl + Super + E`，或 Thunar 右键「在此处打开终端」。

#### 导航

| 按键 | 功能 |
| --- | --- |
| `j`/`k` | 下/上一项 |
| `h`/`l` | 返回上级/进入目录 (同 `Enter`) |
| `J`/`K` | 快速下/上翻半页 (同 `Ctrl+D`/`Ctrl+U`) |
| `gg`/`G` | 跳到首项/末项 |
| `H`/`L` | 后退/前进浏览历史 |
| `[`/`]` | 切换到父目录/首个父目录 |
| `{`/`}` | 向上/向下沿目录树移动 |
| `Ctrl+R` | 刷新当前目录 |
| `Ctrl+L` | 重绘窗口 |
| `Ctrl+C` | 中止当前操作 |

#### 文件操作

| 按键 | 功能 |
| --- | --- |
| `Space` | 标记/取消标记文件 |
| `v` | 全选标记 (可切换) |
| `V` | 可视模式选择 |
| `t` | 打标签，`ut` 移除标签，`"<任意键>` 按标签跳转 |
| `F2` | 重命名 (原名预填) |
| `F3` | 预览文件 |
| `F4` | 编辑器打开 |
| `F5`/`F6` | 复制/剪切 |
| `F7` | 新建目录 |
| `F8` | 删除 |
| `F10`/`q` | 退出 |
| `Q` | 全部退出 (同 `ZZ`) |

#### 命令与控制台

| 按键 | 功能 |
| --- | --- |
| `:` 或 `;` | 打开命令控制台 |
| `s` | 在 shell 中执行命令 |
| `!` | 在 shell 中执行命令 (`-p` 暂停) |
| `r` | 选择程序打开文件 |
| `f` | 查找 (`find`) |
| `cd` | 切换目录 |
| `w` | 显示任务列表 |
| `W` | 显示日志 |
| `S` | 打开当前 shell |
| `?` | 帮助 |
| `~` | 切换视图模式 |
| `R` | 刷新当前目录 |
| `Mf`/`Mi`/`Mm`/`Mp`/`Ms` | 切换行长显示: 文件名/文件信息/修改时间/权限/大小时间 |

## Neovim (文本编辑器)

启动: 双击文本文件，或在终端执行 `nvim`。

> <leader> 为空格键；<C-x> 表示 Ctrl+x。

| --- | --- |

## Zsh (Shell)

系统使用 grml 的 zsh 配置 (`/etc/zsh/zshrc`，`~/.zshrc` 为其副本)，默认 Emacs 键位:

| 按键/命令 | 功能 |
| --- | --- |
| `↑`/`↓` | 按前缀搜索历史命令 |
| `PageUp`/`PageDown` | 按开头搜索上/下一条历史 |
| `Ctrl+R` | 反向增量搜索历史 |
| `Tab` | 补全 (`completeinword` 支持词内补全) |
| `Ctrl+X .` | 补全当前路径 (`zleiab`) |
| `Ctrl+X f` | 插入文件列表 |
| `Ctrl+X p`/`Ctrl+X P` | 历史前缀向后/向前搜索 |
| `Ctrl+X z` | 查看 zle 快捷键帮助 |
| `Ctrl+X b` | 显示缩写列表 |
| `Ctrl+X M` | 原地创建目录 |
| `Esc e` | 在编辑器中编辑当前命令行 |
| `Alt+v` | 按斜杠删除前一个单词 |
| `Insert` | 切换覆盖模式 |
| `..` `...` `....` | 快速向上多级目录 |
| `dir` | `ls -lSrah` (按修改时间排序的详细列表) |

自动行为: 自动 `cd` (`auto_cd`) 、历史共享与追加、历史忽略空格开头的命令、`pushd` 自动入栈。
