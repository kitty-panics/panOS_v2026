# 桌面环境（XFCE 4）

## 面板

底部任务栏（随分辨率自动调整），从左到右：

- 应用程序菜单（蓝色旗帜状启动图标，尺寸随分辨率自动缩放）
- 数字日期时间时钟（Liberation Mono 等宽字体）
- 窗口按钮（任务列表，分组显示、平面按钮）
- 系统托盘（通知、网络管理器、音量、剪贴板管理器 clipman 等）
- 工作区切换器

## 窗口管理器（xfwm4）

- 按钮布局 `C|HM`（关闭在左，最小化/最大化在右）
- 最大化时隐藏边框
- 点击聚焦，`Alt` + 左键拖动移动窗口
- 窗口切换带预览（Alt+Tab）

## 桌面图标网格

桌面图标按文件名前缀编号排成多列网格（详见「内置应用」一章的分类表），`auto-fixed-icons` 脚本在启动时按编号自动排列：

- 文件名中第一个数字决定所在列（0/1/2/3 → 四大分类列）
- 同列按文件名排序依次向下排
- 新增桌面图标时按 `编号/名称.desktop` 命名即可自动进入网格

## 自适应 UI 缩放

`auto-scaling-ui` 脚本在每次启动时根据显示器**短边分辨率**自动设置 DPI、字体、面板尺寸等，共四档：

同时联动调整：窗口标题栏字体与主题、GTK 字体、光标大小、whisker 菜单尺寸、
时钟字体、托盘图标尺寸、Qt5/Qt6 字体，以及 GTK 文件选择器的窗口尺寸与排序规则。

## 壁纸

`auto-wallpaper` 在 xfdesktop 就绪后为每个显示器应用预设壁纸 `/usr/share/backgrounds/xfce/xfce-teal.svg` —— 青绿色渐变，与系统整体风格一致。

## 终端（xfce4-terminal）

- 深色半透明背景（透明度 85%），前景 `#a3a3a3`、背景 `#1f2022`（类 Doom-One 配色）
- 选中即复制，无菜单栏/边框/滚动条
- 无限回滚，中键点击任务栏图标可打开新窗口

## 音频

系统使用 PipeWire 音频栈，音量控制由 TUI 混音器 `wiremix` 提供（支持鼠标操作），见「内置应用」一章。
