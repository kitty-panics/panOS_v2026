# 键盘快捷键

系统预置的常用快捷键尽量贴近 Windows 习惯，上手零成本:

## 启动器与窗口

| 快捷键 | 功能 |
| --- | --- |
| `Super + Return` | 打开终端 (最大化) |
| `Super + R` | 启动器 rofi (相当于 Windows 运行) |
| `Super + E` | 文件管理器 Thunar |
| `Super + I` | 设置管理器 |
| `Super + L` | 锁屏 |
| `Super + P` | 显示器布局 (ARandR) |
| `Super + V` | 剪贴板历史 (clipman) |
| `Alt + F4` | 关闭窗口 |

## 系统与监控

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Shift + Esc` | 任务管理器 (htop) |
| `Ctrl + Super + B` | 蓝牙管理 (bluetui) |
| `Ctrl + Super + N` | 网络连接编辑器 |
| `Ctrl + Shift + Super + B` | 重启 |

## 应用直达

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Super + I` | Chromium 浏览器 |
| `Ctrl + Super + E` | 终端中打开 ranger 文件管理器 |
| `Ctrl + Super + V` | 媒体库播放器 |
| `Ctrl + Super + T` | 文本编辑器 Mousepad |

## 截图 (flameshot)

| 快捷键 | 功能 |
| --- | --- |
| `Shift + Super + S` | 交互式截图 |
| `Ctrl + Shift + Super + S` | 全屏截图 |

## 输入法与剪贴板 (fcitx5)

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Space` | 中英文输入法切换 |
| `Ctrl + ;` | 打开剪贴板 (fcitx5 剪贴板) |
